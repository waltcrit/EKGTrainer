# Regular vs Irregular Rhythms

Assessing rhythm regularity is step 3 in the systematic approach. This single decision splits almost every rhythm into one of a few diagnostic categories.

## The four patterns

| Pattern | Definition | Classic examples |
|---|---|---|
| **Regular** | R–R intervals are constant (±10%) | NSR, SVT, VT, flutter |
| **Regularly irregular** | Irregular, but in a repeating pattern | Wenckebach, bigeminy, trigeminy |
| **Irregularly irregular** | Chaotic, no pattern | Atrial fibrillation, MAT |
| **Chaotic** | Completely disorganized, no true QRS | Ventricular fibrillation |

## How to assess regularity

1. Set calipers to one R–R interval.
2. March them across the strip, stepping from R to R.
3. If every step lands exactly on an R wave: **regular**.
4. If some steps miss slightly but a pattern repeats: **regularly irregular**.
5. If no pattern: **irregularly irregular**.

## The key differential

**Irregularly irregular + no visible P waves = Atrial fibrillation** until proven otherwise.

Other causes of an irregularly irregular rhythm:
- Atrial fibrillation (most common)
- Multifocal atrial tachycardia (MAT) — ≥3 distinct P wave morphologies
- Frequent PACs or PVCs on a sinus background

## Regularly irregular patterns

When you see grouped beating (e.g., pairs of QRS with a pause), think:
- **Wenckebach (Mobitz I)**: PR lengthens, then QRS drops — the group gets longer
- **Bigeminy**: Every other beat is a PVC
- **Trigeminy**: Every third beat is a PVC
- **2:1 block**: Every other P is blocked — looks regular but rate is half the atrial rate

## Clinical significance

The distinction between regular and irregular has immediate management implications:
- A **regular narrow tachycardia** → vagal maneuvers, adenosine
- An **irregularly irregular tachycardia** → rate control, anticoagulation (AFib)
- A **regular wide tachycardia** → treat as VT until proven otherwise
