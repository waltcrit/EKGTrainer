# Normal Sinus Rhythm

**Normal sinus rhythm (NSR)** is the standard, healthy baseline. Every other rhythm is defined by how it deviates from NSR.

## Diagnostic criteria

For a rhythm to be called NSR, **all five** of the following must be true:

1. **Rate**: 60–100 bpm
2. **Rhythm**: Regular (R–R intervals consistent, ±10%)
3. **P waves**: Present before every QRS, upright in lead II, same morphology
4. **PR interval**: 120–200 ms (3–5 small boxes), constant
5. **QRS duration**: ≤ 120 ms (≤ 3 small boxes)

If any criterion is violated, the rhythm is not NSR — even if everything else looks normal.

## What NSR looks like

On a lead II rhythm strip:
- Evenly spaced, narrow QRS complexes at 60–100 bpm
- A small, upright P wave before each QRS, separated by a constant PR interval
- After the QRS, a T wave (upright in lead II)

## Common mimics

| Finding | Why it's not NSR |
| --- | --- |
| Rate > 100 | Sinus tachycardia |
| Rate < 60 | Sinus bradycardia |
| Irregular | Sinus arrhythmia (respiratory variation) — still sinus! |
| No P waves | Junctional, AFib, flutter |
| Wide QRS | BBB, ventricular origin |
| Variable PR | AV block (Wenckebach) |

## Sinus arrhythmia

A slight irregularity of the R–R interval that varies with breathing (increases on inspiration, decreases on expiration) is called **sinus arrhythmia**. It is a normal variant, especially in young people and athletes. The P wave morphology and PR interval remain constant — the only thing changing is the rate.

## Key takeaway

NSR is the reference standard. Learn it cold — every criterion, every feature. When you see a rhythm that deviates, you'll immediately know which criterion is violated and what that implies.
