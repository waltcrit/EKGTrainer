# Atrial Flutter

**Atrial flutter** is a macro-reentrant atrial arrhythmia where the atria depolarize at a very regular rate of approximately **300 bpm** (250–350 bpm). The AV node cannot conduct 300 impulses per minute, so it blocks some in a regular ratio.

## EKG features

- **Sawtooth flutter waves (F-waves)**: regular, negative deflections in II, III, aVF — the classic "sawtooth" pattern
- **Atrial rate**: ~300 bpm (one F-wave every large box)
- **Regular ventricular rate** (unless variable block)
- **No isoelectric baseline** between flutter waves — they are continuous
- **2:1 block** (most common): ventricular rate ~150 bpm → flutter rate ÷ 2

## The "150 bpm rule"

Any narrow complex tachycardia at exactly **150 bpm** is atrial flutter with 2:1 block until proven otherwise.

At 2:1 block, flutter waves may be buried in the QRS and T wave, making them hard to see. To unmask them:
- Apply vagal maneuvers or adenosine — this will temporarily block more F-waves and reveal the sawtooth pattern

## Block ratios

| Block ratio | Ventricular rate |
|---|---|
| 2:1 | ~150 bpm |
| 3:1 | ~100 bpm |
| 4:1 | ~75 bpm |
| Variable | Irregular |

4:1 flutter looks deceptively like sinus rhythm at 75 bpm — count the atrial rate.

## AFib vs flutter

| Feature | AFib | Flutter |
|---|---|---|
| P waves | Absent; fibrillatory | Sawtooth F-waves |
| Atrial rate | 350–600 bpm | ~300 bpm (regular) |
| R–R intervals | Irregularly irregular | Regular (with fixed block) |
| Baseline | Chaotic | Organized sawtooth |
