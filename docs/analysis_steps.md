# EKG Rhythm Analysis Steps

| Analysis step | Differential diagnosis implication |
|---|---|
| 1. Confirm correct patient. | Wrong patient = wrong interpretation. |
| 2. Check prior EKGs. | New change = acute; old change = baseline. |
| 3. Assess rate. | Fast: tachy, SVT, flutter, AF, VT, stress, fever, pain, hypovolemia, anemia, hypoxia. Slow: brady, meds, AV block, hypothyroid, hypothermia, vagal tone. |
| 4. Assess rhythm. | Regularly irregular = AV block, flutter w/ block, PACs/PVCs, sinus arrhythmia. Irregularly irregular = AF, MAT, ectopy. |
| 5. Check P before each QRS. | Missing P = AF, junctional, sinus arrest, AV dissociation. Extra P = AV block, flutter. Disconnected Ps/QRSs = 3° AVB. |
| 6. Measure intervals. | PR long = 1° AVB; short = pre-excitation/junctional. QRS wide = BBB, VT, pre-excitation, hyperK. QT long = torsades risk, drugs, electrolytes, LQTS. |
| 7. Evaluate P waves. | Abnormal P = atrial enlargement or ectopic atrial rhythm. Inverted inferior P = junctional/low atrial. |
| 8. Evaluate axis. | LAD: LAFB, LVH, inferior MI. RAD: RVH, RV strain, lung disease. Extreme: lead reversal, ventricular rhythm, severe conduction disease. |
| 9. Check precordial progression. | Poor progression = anterior MI, lead misplacement, LBBB, RVH, COPD, normal variant. |
| 10. Check ST segments. | STE = STEMI, pericarditis, early repol, LVH, Brugada. STD = ischemia, reciprocal change, digoxin, strain. |
| 11. Check T waves. | Inversion = ischemia, strain, BBB, RVH, PE, CNS event, normal variant. Peaked = hyperK. Flat/biphasic = ischemia, electrolytes, meds. |
| 12. Check Q waves. | Pathologic Q = prior MI/scar, cardiomyopathy, lead issue. |
